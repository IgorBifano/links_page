# Criar um agregador de links premium para Igor Bifano

Crie um site de agregador de links de alto nível para **Igor Bifano**.

Isso NÃO é um Linktree genérico.
Isso NÃO é uma lista simples de botões.
Isso deve parecer um **hub premium de marca pessoal**, com estética moderna, escura e sofisticada.

O objetivo é impressionar imediatamente e, ao mesmo tempo, manter simplicidade e foco.

---

## Objetivo principal

Essa página serve para:

1. causar uma ótima primeira impressão
2. centralizar links importantes
3. transmitir autoridade
4. funcionar perfeitamente no mobile
5. servir como base até o site completo ser criado depois

---

## Stack tecnológica

Use:

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

O código deve ser:
- responsivo
- limpo
- organizado
- pronto para produção
- fácil de editar depois

---

## Direção de design

Criar uma interface **dark premium** com leve estética futurista.

### Estilo visual

- fundo: preto profundo ou carvão
- cards: cinza escuro com profundidade
- cores de destaque: verde neon, ciano elétrico ou magenta (usar com moderação)
- tipografia: moderna, limpa e forte
- espaçamento: elegante e bem distribuído
- sombras/glow: sutis e sofisticados
- cantos: levemente arredondados
- animações: suaves e bem feitas

### Evitar

- visual genérico de Linktree
- excesso de cores
- estilo gamer ou exageradamente cyberpunk
- poluição visual
- aparência de template pronto
- gradientes exagerados

---

## Experiência do usuário

Deve funcionar muito bem no mobile, mas também ficar bonito no desktop.

A página deve parecer:

- simples, mas poderosa
- rápida de navegar
- organizada
- com identidade forte
- com sensação premium

---

## Estrutura da página

### 1. Hero (topo)

Deve conter:

- foto ou área visual de perfil
- nome: Igor Bifano
- uma frase curta de posicionamento
- um pequeno texto de apoio
- animação suave na entrada

Direção do conteúdo:

- engenharia de software
- IA
- sistemas
- criação
- educação

---

### 2. CTA principal (destaque)

Um botão ou card principal no topo.

Exemplo:

- Formação Engenharia de Aplicação
- Entrar na lista
- Conhecer a formação

Esse elemento deve se destacar visualmente mais que os outros.

---

### 3. Seções de links organizadas

Não usar lista solta. Organizar por categorias.

#### Aprender
- Formação Engenharia de Aplicação
- Página futura do curso
- Lista de espera

#### Projetos
- Simias
- Simetrya
- Primal Enterprises

#### Conteúdo
- Blog
- Artigos
- Estudos

#### Contato
- WhatsApp
- Instagram
- Email

Cada grupo deve ter:

- título claro
- bom espaçamento
- animação leve
- cards bem desenhados

---

### 4. Seção de autoridade

Uma área compacta com credibilidade.

Exemplo:

- +70h de conteúdo
- certificado exclusivo
- projetos reais
- foco em IA e sistemas

Essa parte deve ser visualmente forte, mas não grande.

---

### 5. Final / rodapé

Área final simples e elegante:

- frase curta de posicionamento
- links principais
- redes sociais
- rodapé minimalista

---

## Design dos cards de link

Cada link deve parecer premium.

Requisitos:

- design próprio (não padrão)
- animação ao passar o mouse/toque
- suporte a ícones
- espaçamento consistente
- sensação clara de clique

O CTA principal deve ser diferente dos demais.

---

## Animações

Usar Framer Motion para:

- entrada suave dos elementos
- animações em sequência (stagger)
- leve elevação no hover
- pequenos efeitos de glow
- transições suaves entre seções

Evitar exagero.

---

## Estrutura de conteúdo

Separar conteúdo do layout.

Criar um arquivo tipo:

- `/data/site-content.ts`

Esse arquivo deve conter:

- dados do perfil
- textos do hero
- links organizados
- itens de autoridade
- contatos

Assim fica fácil editar depois.

## Critério final

Antes de finalizar, verificar:

- parece premium ou genérico?
- parece um projeto personalizado?
- impressiona no primeiro acesso?
- funciona muito bem no mobile?
- não parece um Linktree comum?

Se não estiver nesse nível, melhorar.

Importante:

Não criar um layout genérico.
Não usar botões padrão empilhados no centro.
Não fazer um clone simples de Linktree.

O design deve parecer uma marca pessoal premium.

Priorizar:
- estética dark sofisticada
- espaçamento bem pensado
- animações refinadas
- design customizado de cards
- experiência mobile excelente

O resultado deve parecer um hub de marca pessoal de alto nível.
